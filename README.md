# Beauty Hub Central

A beauty salon and parlour booking platform built with React, TypeScript, Node.js, and PostgreSQL.

## Features

- City selection
- Parlour browsing
- Service booking
- Staff management
- Gallery images
- Reviews and favourites
- User authentication
- Owner dashboard

## Tech Stack

- React
- TypeScript
- Vite
- Node.js
- Express
- PostgreSQL
- Replit
